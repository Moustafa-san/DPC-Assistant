# ADR-003 — التوجيه واللغات وروابط العميل
**الحالة:** مقترح يحتاج اعتماد.

**السياق:** §5.3 يصف `/` واحداً لقيود المعاينة؛ §8.1 يذكر صفحات لغة منفصلة؛ روابط العميل تحتاج عنواناً قابلاً للمشاركة.
**المقترح:** `/ar` و`/en` للهبوط و`/<locale>/p/<token>` للصفحات العامة، مع تنقل داخلي لباقي التطبيق إذا أقرته UX.
**البدائل:** كل الشاشات مسارات مستقلة؛ SPA أحادي المسار بالكامل.
**الاعتبارات:** SEO وdeep links وrefresh/history والمشاركة واختبارات locale.
**الحسم:** اعتماد UX وتجربة Next.js App Router.
