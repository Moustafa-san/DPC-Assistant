# ADR-010 — اعتماد الترقيم الذري للفواتير والدفعات المستقلة ودفتر الدخل
**الحالة:** Accepted — معتمد هندسياً في Gate 4.
**النطاق:** إصدار الفواتير، تسجيل الدفعات الجزئية، ودفتر الأستاذ المالي (Income Ledger).

## السياق
حدوث تكرار في أرقام الفواتير تحت وطأة تزامن الطلبات، أو تكرار قيد دفعة نقدية مرتين في دفتر الدخل، يهدد سلامة السجلات المالية ومصداقية المصور أمام مصلحة الضرائب والعملاء.

## القرار
1. **الترقيم الذري للفواتير:** فرض قيد فريد صارم على مستوى قاعدة البيانات:
   ```sql
   CONSTRAINT unique_owner_invoice_number UNIQUE (owner_id, invoice_number)
   ```
   يمنع تكرار رقم الفاتورة لنفس المصور منعاً باتاً.
2. **استقلالية الدفعات ومفاتيح منع التكرار:** كل دفعة جزئية تعامل كمعاملة مستقلة محمية بقيد فريد:
   ```sql
   CONSTRAINT unique_owner_payment_idempotency UNIQUE (owner_id, idempotency_key)
   ```
   بحيث تفشل أي محاولة لإعادة إرسال نفس الدفعة بالخطأ.
3. **دفتر الدخل النقدي (Cash Basis):** لا يتم قيد دخل الفاتورة إطلاقاً عند إصدارها، بل يُسجل الدخل فقط عند الاستلام الفعلي للدفعة ويُربط بنفس مفتاح العملية.
4. **حظر مبدأ Last-Write-Wins:** منع التحديث العشوائي الأخير للمعاملات المالية؛ التعديل يتم فقط عبر قيود تسوية موثقة.

## العواقب
- دقة مالية مطلقة وانعدام احتمالية التكرار المالي أو مضاعفة قيود الدخل.
