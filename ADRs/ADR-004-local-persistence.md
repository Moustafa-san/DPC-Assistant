# ADR-004 — اعتماد التخزين المحلي المعزول للحسابات (Account-Isolated Offline Queue)
**الحالة:** Accepted — معتمد هندسياً في Gate 4.
**النطاق:** التخزين المحلي، إدارة العمل دون اتصال، وحماية الأجهزة المشتركة.

## السياق
يحتاج التطبيق لدعم العمل الميداني دون اتصال بالإنترنت في مواقع التصوير. التخزين العام العشوائي أو استخدام SQLite WASM يضيف تعقيداً مفرطاً، بينما localStorage محدود الحجم. كما أن خطر بقاء بيانات المستخدم على أجهزة مشتركة يتطلب عزلاً صارماً لكل حساب.

## القرار
1. اعتماد **Zustand** لإدارة حالة واجهة المستخدم المحلية اللحظية.
2. اعتماد نمط المستودع المجرد (**Repository Adapter Pattern**) مع طابور عمليات معزول للحسابات (`OfflineQueueManager` تحت `src/lib/repositories/offline-queue.ts`).
3. كل عملية محلية تحمل معرفاً فريداً (`operationId`) ورقم إصدار قاعدي (`baseVersion`) وتاريخ الإنشاء.
4. عزل كامل للبيانات والطابور حسب `userId`؛ لا تظهر عمليات مستخدم لمستخدم آخر.
5. توفير مسح فوري للبيانات المحلية والطابور (`purgeUserData`) عند تسجيل الخروج أو عند طلب المستخدم لمسح الذاكرة المؤقتة لمنع تسريب البيانات على الأجهزة المشتركة.

## العواقب
- حماية فائقة للخصوصية ومنع تسريب بيانات العملاء على الأجهزة المشتركة.
- جاهزية تامة للمزامنة السحابية الموثوقة دون تعارضات خفية.
