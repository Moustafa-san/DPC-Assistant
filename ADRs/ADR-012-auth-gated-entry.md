# ADR-012 — بوابة الدخول وإلغاء Guest Mode في الإصدار الأول
**الحالة:** Accepted — اعتمده مالك المنتج صراحةً بتاريخ 2026-11-03.
**النطاق:** رحلة المستخدم، المصادقة، مساحة العمل، التخزين المحلي وOffline في MVP.

## السياق
كانت وثائق المنتج الأصلية تصف Guest Mode لبعض الأدوات. ثم حُدد المسار الأساسي ليبدأ بصفحة Landing ثم التسجيل/الدخول. حُسم الآن السؤال المتبقي: لا يوجد مسار Guest ثانوي في الإصدار الأول.

## القرار
1. Landing Page والصفحات التعريفية/المساعدة العامة متاحة دون حساب.
2. زر «ابدأ الآن» من أي موضع ينقل إلى Authentication.
3. جميع أدوات التطبيق ومساحة العمل تتطلب نجاح المصادقة؛ لا توجد أداة قابلة للاستخدام كضيف في MVP.
4. لا يوجد زر «جرّب كضيف» ولا Guest Mode ثانوي في الإصدار الأول.
5. وسائل المصادقة في UX الحالي: البريد الإلكتروني/كلمة المرور وGoogle OAuth. Magic Link غير معتمد للتنفيذ حتى قرار منفصل.
6. بعد نجاح المصادقة ينتقل المستخدم إلى Home / My Projects.
7. لا يوجد Guest-to-Account migration ضمن MVP؛ تزال متطلباته من خطة التنفيذ والاختبارات ونموذج البيانات.
8. الصفحات العامة وروابط العميل ذات token محدود الصلاحية تظل متاحة ضمن النطاق المصرح به فقط؛ ولا تعد Guest Mode أو وصولاً إلى مساحة العمل.
9. Offline يخص بيانات حساب سبق أن تمت مصادقته وتحميل بياناته محلياً. يجب عزل IndexedDB/cache/queue حسب الحساب وتحديد سلوك logout وانتهاء الجلسة وتبديل الحساب قبل الإطلاق.
10. غياب إعداد Supabase لا يسمح بتجاوز المصادقة. يمكن تقديم Landing والمحتوى العام، بينما تعرض مسارات Auth/Workspace حالة إعداد واضحة.

## الأثر
- إزالة Guest Mode من نطاق MVP وواجهاته ومتطلباته.
- إزالة Guest-to-Account merge من Data Model وImplementation Plan وThreat Model والاختبارات.
- تحديث PRD وUX وArchitecture وData Model وThreat Model وPrivacy Risk Screen وImplementation Plan وCLAUDE.md.
- تبقى مخاطر cache على الأجهزة المشتركة وعزل الحسابات ضمن نطاق التهديدات والخصوصية.
- لا يتغير دعم الروابط العامة المحدودة للعملاء.

## خارج القرار
- لا يحدد هذا ADR مزود SMTP أو مدة تأكيد البريد.
- لا يحسم Magic Link.
- لا يحسم تفاصيل سياسات Offline عند انتهاء الجلسة؛ يجب توثيقها في ADR/تصميم Auth & Sync قبل الإطلاق.

## معايير القبول
- الزائر يستطيع استعراض Landing والصفحات العامة فقط.
- لا يوجد CTA أو route أو API يتيح استخدام الأدوات دون مصادقة.
- الضغط على «ابدأ الآن» ينقل إلى Authentication.
- بعد تسجيل/دخول ناجح ينتقل المستخدم إلى Home / My Projects.
- الروابط العامة المصرح بها تعمل بنطاقها المحدود دون كشف بيانات داخلية.
- اختبارات E2E تثبت عدم وجود bypass عند غياب إعداد Supabase.
- لا توجد جداول أو migrations أو اختبارات أو مهام Guest merge في MVP.
