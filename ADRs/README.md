# سجل ADRs (Architectural Decision Records)

سجل القرارات المعمارية المعتمدة والمقترحة لمشروع مساعد المصور:

- **ADR-001 (Accepted):** اعتماد npm كمدير الحزم الرسمي الوحيد للمشروع وقفل `package-lock.json`.
- **ADR-002 (Accepted):** اعتماد Vitest لاختبارات المنطق النقي وPlaywright لاختبارات E2E.
- **ADR-003 (Proposed):** هيكلة المسارات واللغات (`/ar`, `/en`, `/<locale>/p/<token>`).
- **ADR-004 (Accepted):** اعتماد التخزين المحلي المعزول للحسابات وطابور العمليات دون اتصال (Offline Queue).
- **ADR-005 (Open):** مزود SMTP لرسائل Supabase Auth وسياسة التحقق من البريد.
- **ADR-006 (Accepted):** اعتماد تحديد معدل الطلبات للروابط العامة (Token-Level Rate Limiting).
- **ADR-007 (Accepted):** حقول عرض السعر للعميل في ProCost وتطهير التكاليف وهوامش الربح الداخلية.
- **ADR-008 (Open):** تقييم الحجز وجدوى استبعاده من MVP أو بقائه ملاحظة خاصة بالمصور.
- **ADR-009 (Proposed):** بيانات المعدات وأسعار الصرف وتحديثها يدوياً أولاً.
- **ADR-010 (Accepted):** اعتماد الترقيم الذري للفواتير والدفعات المستقلة ودفتر الدخل النقدي.
- **ADR-011 (Accepted):** سياسات فض التعارضات والمزامنة دون اتصال (منع LWW المالي والدمج التجميعي).
- **ADR-012 (Accepted):** بوابة الدخول المعتمدة والمصادقة الإلزامية لمساحة العمل والأدوات في MVP.
