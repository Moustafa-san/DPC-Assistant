# ADR-006 — اعتماد تحديد معدل الطلبات للروابط العامة (Token-Level Rate Limiting)
**الحالة:** Accepted — معتمد هندسياً في Gate 4.
**النطاق:** الروابط العامة للعملاء (البريف، عروض الأسعار، الحجوزات، والفواتير).

## السياق
الروابط العامة المفتوحة للعملاء تمثل نقطة تماس خارجية قد تتعرض لمحاولات تخمين الرموز (Brute Force) أو إغراق الخادم بالطلبات (Denial of Service). بيئات Serverless على Vercel لا تحتفظ بذاكرة مشتركة دائمة بين الحاويات.

## القرار
1. حماية الروابط العامة بالاعتماد على رموز عشوائية مشفرة عالية التشتت (256-bit Entropy).
2. تطبيق نافذة زمنية منزلقة لتحديد معدل الطلبات مسجلة في سجل الرمز في قاعدة البيانات (`public_tokens`) وتطبق عبر `validatePublicToken`:
   - سقف أقصى: **30 طلباً في الدقيقة** لكل رابط.
   - نافذة فحص مدتها 60 ثانية تتجدد تلقائياً.
3. الرفض الفوري بحالة `RATE_LIMITED` عند تجاوز الحد.
4. حظر تسجيل محتوى الطلبات أو عناوين IP الكاملة لضمان الخصوصية وتقليل البيانات.

## العواقب
- حماية الروابط العامة وموارد الخادم من الاستنزاف والتخمين الآلي دون تكلفة بنية تحتية إضافية.
