# UX_DESIGN — ملحق تغيير معتمد
التاريخ: 2026-11-03 | الحالة: معتمد لإدراجه في UX_DESIGN v0.3.0

## المسار الرئيسي
Landing Page → «ابدأ الآن» → Authentication → Home / My Projects → الأدوات.

- كل CTA «ابدأ الآن» يفتح شاشة المصادقة.
- لا يوجد زر «جرّب كضيف» ولا Guest Mode في الإصدار الأول.
- لا يمكن فتح الأدوات أو مساحة العمل دون تسجيل الدخول.
- «استكشف الأدوات» ينقل إلى قسم تعريفي داخل Landing فقط.
- خيارات المصادقة الحالية: البريد الإلكتروني/كلمة المرور وGoogle OAuth.
- المستخدم الجديد يصل إلى Empty State في Home، والمستخدم العائد يصل إلى Home مباشرة.
- لا يؤدي غياب إعداد Supabase أو انقطاع الاتصال إلى تجاوز المصادقة.
- الصفحات العامة وروابط العميل المحدودة تبقى متاحة وفق نطاقها فقط.
- Offline للحسابات المصادق عليها مع عزل البيانات المحلية لكل حساب.

## الأثر
تحذف شاشات ومسارات Guest ومتطلبات Guest-to-Account migration من UX MVP. تظل سياسات logout وتبديل الحساب وعزل cache ضمن متطلبات التصميم.

المرجع: ADR-012 (Accepted).
