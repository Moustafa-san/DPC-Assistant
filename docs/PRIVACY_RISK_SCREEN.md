# PRIVACY_RISK_SCREEN — فحص مخاطر الخصوصية
الإصدار 0.1.0 | Gate 1 Draft. هذا فحص أولي وليس DPIA قانونياً أو رأياً قانونياً.

## البيانات والأغراض
|الفئة|أمثلة|الغرض|
|---|---|---|
|الحساب|البريد ومعرف Auth واللغة|الدخول والمزامنة|
|العملاء|الاسم ووسائل الاتصال والملاحظات|CRM والمشروعات|
|المشروع|Brief ومواعيد وتفاصيل إنتاج|تنفيذ العمل|
|المال|Quote/Invoice/Payments/Expenses|التسعير والتحصيل|
|الملفات|شعار وصور مرجعية|وظائف يطلبها المستخدم|
|تقنية|sync status وأخطاء وأحداث أمن|التشغيل والحماية|
|روابط عامة|token hash وexpiry وscope|مشاركة محدودة|

لا حاجة حالياً لجمع هوية رسمية أو GPS مستمر أو بيانات دفع مصرفية.

## تدفق البيانات
لا يوجد Guest Mode في MVP. بيانات مساحة العمل: Supabase بعد المصادقة وفق إعدادات الحساب؛ وأي cache/Offline محلي يكون scoped للحساب المصادق عليه. التطبيق: Vercel. البريد: Supabase Auth عبر SMTP provider غير محدد. الروابط العامة: endpoint محدود. GitHub: كود بعد موافقة المالك فقط. لا مشاركة معلنة مع إعلان/وسيط بيانات.

## تقليل البيانات
- لا تجمع حقولاً غير لازمة.
- لا تسجل محتوى البريف أو الفاتورة أو token في logs.
- لا ترسل بيانات العميل لخدمات خارجية أو AI دون موافقة منفصلة.
- لا تضف analytics أو crash reporting خارجي قبل تقييم وموافقة.
- لا تجمع GPS مستمراً؛ إحداثيات المكان فقط إذا أدخلها المستخدم لغرض الشمس.
- استخدم بيانات اصطناعية في الاختبارات.
- وضح مخاطر بقاء cache/Offline لحساب مصادق عليه على جهاز مشترك، ووفّر عزلاً واضحاً بين الحسابات وسلوك logout مناسباً.

## مخاطر وتخفيف
|ID|الخطر|التخفيف|
|---|---|---|
|P01|الرابط يكشف أكثر من اللازم|field allowlist وscope وexpiry/revoke|
|P02|بيانات Offline لحساب على جهاز مشترك أو بعد تبديل الحساب|عزل حسب الحساب، سلوك logout واضح، ومسح محلي مناسب|
|P03|PII في logs|redaction وعدم تسجيل payload|
|P04|مزود البريد يعالج بيانات اتصال|تقييم provider والموقع والتكلفة|
|P05|مستخدم لا يفهم cloud sync|إيضاح قبل الحفظ السحابي|
|P06|نسخ غير مشفرة|تشفير موثوق واختبار restore|
|P07|احتفاظ غير محدود|سياسة retention|
|P08|إرسال صورة لطرف ثالث|موافقة صريحة منفصلة|
|P09|تصدير/حذف ناقص|inventory لكل مخزن ونسخة|
|P10|بيانات حقيقية في الاختبار|fixtures اصطناعية|

## الشفافية وحقوق المستخدم
سياسة الخصوصية تشرح البيانات والغرض والتخزين السحابي وبيانات Offline المحلية والمعالجين ومواقع البيانات ومدة الاحتفاظ والنسخ الاحتياطية والتصدير والحذف وإبطال الروابط ووسيلة التواصل.

## قرارات مفتوحة
مدة الاحتفاظ بعد الحذف؛ مدة بقاء النسخ؛ Supabase region؛ SMTP provider؛ رفع الصور في MVP؛ الحد الأدنى للسجلات الأمنية؛ المتطلبات القانونية حسب البلدان. يلزم رأي قانوني قبل الإطلاق العام في الأسواق المستهدفة.

## النتيجة
أعلى المخاطر: بيانات العملاء والمال، الروابط العامة، التخزين المحلي على جهاز مشترك، النسخ الاحتياطية، ومزود البريد. يستمر التصميم مع الضوابط، ولا تطلق المشاركة العامة أو المزامنة الإنتاجية قبل إغلاق المخاطر الحرجة.
