# PRD — ملحق تغيير معتمد بقرار المالك
التاريخ: 2026-11-03 | الحالة: معتمد لتحديث PRD عند دمج الوثائق

## قرار المسار والدخول
المسار الأساسي: Landing Page → «ابدأ الآن» → إنشاء حساب/تسجيل دخول → Home / My Projects → استخدام الأدوات.

- جميع الأدوات ومساحة العمل تتطلب المصادقة الناجحة.
- لا يوجد Guest Mode أو زر «جرّب كضيف» في الإصدار الأول.
- لا يوجد Guest-to-Account migration ضمن MVP، وتحذف متطلباته من معايير القبول وخطة التنفيذ والاختبارات.
- وسائل المصادقة في UX الحالي: البريد الإلكتروني/كلمة المرور وGoogle OAuth. Magic Link غير معتمد حتى قرار منفصل.
- تظل Landing والصفحات العامة وروابط العميل ذات النطاق المحدود متاحة دون حساب، دون فتح الأدوات أو مساحة العمل.
- غياب إعداد Supabase لا يسمح بتجاوز المصادقة.
- Offline يخص حساباً مصادقاً عليه مع عزل cache/queue حسب الحساب.

## أثر التغيير على PRD
- يستبدل هدف «تجربة الأدوات دون حساب» بهدف استعراض المنتج والصفحات العامة دون حساب.
- يستبدل FR-01 بمتطلب Auth Gate، ويحذف FR-03 الخاص بترحيل Guest.
- تزال Guest merge من المخاطر وخطة التنفيذ والاختبارات؛ وتبقى مخاطر عزل البيانات المحلية على الأجهزة المشتركة.
- يحتفظ PRD بتاريخ نسخته السابقة، ويسجل هذا القرار في سجل التغييرات بدلاً من محو التاريخ.

المرجع: ADR-012 (Accepted).
