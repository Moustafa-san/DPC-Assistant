# PRD — مساعد المصور
الإصدار 0.1.0 | Gate 1 Draft

## 1. الملخص
مساعد المصور نظام تشغيل أعمال للمصور المستقل ومصور الفيديو، يربط رحلة العمل من استقبال البريف إلى التسعير والتخطيط والتصوير والفوترة والتحصيل، مع طبقة لإدارة العملاء والمهام وربحية النشاط.

**عرض القيمة:** «من البريف للفلوس — كل أدوات شغلك في مكان واحد». المنتج مجاني ومفتوح المصدر GPL-3.0، بلا اشتراكات أو عمولات أو إعلانات أو تتبع خارجي أو بيع بيانات.

## 2. المشكلة والجمهور
يعتمد المصور المستقل على أدوات وملفات متفرقة لإدارة الطلبات والتسعير واللقطات والمواعيد والفواتير والتحصيل. ينتج عن ذلك إعادة إدخال البيانات وفقد السياق وضعف رؤية التكلفة والربحية. هذه صياغة مستنتجة من الوثائق وليست بحث مستخدمين موثقاً.

الجمهور الأساسي: مصورو الصور والفيديو المستقلون في مصر والعالم العربي. الثانوي: المصورون عالمياً عبر الواجهة الإنجليزية. لا توجد مقابلات أو بيانات كمية موثقة حتى الآن.

## 3. أهداف المنتج
1. ربط أدوات التصوير في سير عمل متصل.
2. استعراض المنتج والصفحات العامة دون حساب، مع اشتراط المصادقة لاستخدام الأدوات.
3. الحفظ والمزامنة السحابية للحسابات المصادق عليها.
4. تقليل إدخال البيانات المتكرر.
5. حسابات مالية وتخزينية موثوقة.
6. Offline في السيناريوهات المحددة.
7. حماية البيانات وتمكين التصدير والحذف.
8. العربية/الإنجليزية وRTL/LTR حقيقيان.

## 4. نطاق المنتج
### الأدوات السبع
- Brief Builder: متطلبات العميل ورابط مشاركة آمن.
- ProCost: تكلفة وسعر وربح وقاعدة معدات إرشادية ونسختا عرض سعر.
- Pro Shotlist: قوالب لقطات وترتيب ومعدات وإنجاز Offline.
- Cine Palette: استخراج ألوان و60/30/10 ومودات وتصدير LUT.
- Calendar: توافر وحجوزات وOrder Sheet ومواقيت الشمس.
- Pro Invoice: فواتير ثنائية اللغة وشعار وPDF ودفعات جزئية.
- Storage Calculator: مساحة الفيديو والصور والاحتياطي وعدد البطاقات.

### طبقة الأعمال
- Tasks: مهام Pre / Day-Of / Post.
- CRM: العملاء والفرص وسجل التعامل.
- Business Dashboard: دخل ومصروفات وإهلاك وقيمة ساعة العمل وربحية وBuy-vs-Rent.

### التكاملات
Brief→ProCost؛ Quote→Shotlist؛ Shotlist→Gear checklist/Order Sheet؛ Storage→ProCost؛ Calendar→Tasks/Order Sheet؛ Payments→Income ledger؛ CRM + expenses + depreciation + time→Dashboard.

## 5. الدخول والحساب
**قبل تسجيل الدخول:** Landing والصفحات التعريفية والمساعدة العامة فقط. لا يمكن استخدام أدوات التطبيق أو مساحة العمل دون حساب.
**بعد تسجيل الدخول:** تتاح الأدوات والمشروعات والحفظ والمزامنة السحابية وفق صلاحيات الحساب.

المسار الأساسي: Landing Page → «ابدأ الآن» → إنشاء حساب/تسجيل دخول → Home / My Projects → استخدام الأدوات.

طرق المصادقة المعتمدة في UX الحالي: البريد الإلكتروني/كلمة المرور وGoogle OAuth. Magic Link غير معتمد للتنفيذ حتى قرار منفصل. لا يوجد Guest Mode أو زر «جرّب كضيف» في الإصدار الأول، ولا يوجد Guest-to-Account migration ضمن نطاق MVP. لا يجوز أن يؤدي غياب إعداد Supabase أو انقطاع الاتصال إلى فتح الأدوات دون مصادقة.

تظل الصفحات العامة وروابط العميل ذات النطاق المحدود متاحة دون حساب؛ ولا يعد ذلك Guest Mode أو وصولاً مجهولاً إلى مساحة العمل. Offline يخص بيانات حساب سبق أن تمت مصادقته وحمّل بياناته محلياً، مع عزل البيانات والطابور حسب الحساب ومعالجة آمنة لتسجيل الخروج وتبديل الحساب.

## 6. خارج النطاق
الأكاديمية والدورات والشهادات، محاكي كاميرا/إضاءة، المحادثات الداخلية، معرض الأعمال العام/شبكة اجتماعية، محرر فيديو (المسموح تتبع مهام المونتاج)، الدفع والاشتراكات والعمولات والسوق والإعلانات، الرسائل الجماعية الآلية، إرسال بيانات العميل لخدمات خارجية أو AI دون موافقة صريحة.

## 7. المتطلبات غير الوظيفية
Next.js 16 App Router؛ TypeScript strict؛ Tailwind 4؛ shadcn/ui؛ Zustand؛ Zod؛ Supabase PostgreSQL/Auth/RLS؛ Vercel؛ PWA؛ العربية والإنجليزية؛ Mobile-first؛ WCAG 2.2 AA كهدف؛ RLS واختبارات عزل؛ لا وصول للأدوات دون مصادقة؛ لا implicit Guest fallback عند غياب مفاتيح Supabase.

## 9. قواعد المال
العملات EGP/USD/SAR/AED. لا تجمع عملات مختلفة دون تحويل صريح وسعر صرف محفوظ. تخزين المبالغ integer minor units من البداية؛ لا floating point. كل دفعة معاملة مستقلة؛ idempotency لمنع تكرار الدخل؛ ترقيم الفواتير ذري. لا تسجل كامل الفاتورة كدخل عند دفع جزء فقط.

## 10. المخاطر
PDF عربي يحتاج spike في Gate 2؛ عزل offline cache بين الحسابات وoffline conflicts؛ RLS والروابط العامة؛ SMTP؛ DST؛ صحة LUT؛ وعدد التبويبات الثمانية يحتاج اعتماد UX.

## 11. مؤشرات مقترحة
إكمال Brief→Quote→Shotlist؛ تحويل الزائر إلى التسجيل/الدخول عبر CTA؛ المشاريع التي تصل لفاتورة؛ سلامة ترحيل الدفعات؛ نجاح المزامنة؛ أخطاء الحسابات؛ زمن المهام الأساسية. هذه مؤشرات مقترحة بلا أهداف رقمية معتمدة. لا تضف analytics خارجية دون موافقة.
